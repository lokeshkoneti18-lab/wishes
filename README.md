# Happy birthday, VADINA garu

A small, self-contained birthday greeting with animated canvas fireworks, responsive photo-collage backgrounds, and a gallery of the photos in this folder.

## Open the page

Open `index.html` in a browser. No installation or build step is needed. Keep `background.png`, `background2.png`, and the JPEG photos beside `index.html`; the portrait image is used on mobile and the wide image on desktop.

Use **Replay fireworks** to launch another celebration. Fireworks are disabled when the device requests reduced motion.
